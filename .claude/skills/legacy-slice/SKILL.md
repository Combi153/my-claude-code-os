# Legacy slice migration

Move one seam function's worth of a legacy PHP backend into Spring/Kotlin without changing what the screen does, and prove both halves of that claim. 두 오라클이 왜 둘인지와 원장의 열 계약은 주입된 컨텍스트에 있다. 설계 근거는 `docs/legacy-migration-os.md`(1.6장이 v3), 포맷 정본은 `references/ledger-format.md`.

완전성의 정적 검사는 각각 한 층만 보므로 층이 하나 생기면 사각지대가 하나 생긴다. **독 주입은 층에 무관하다** — `migrated` 모드에서 래퍼의 레거시 반환값을 독으로 바꿔도 화면이 그대로면 그 값은 백엔드에서 왔다.

## 현재 상태

!`bash "${CLAUDE_PROJECT_DIR:-.}/.claude/skills/legacy-slice/status.sh"`

## 단위와 산출물

**작업 단위는 이음새 함수 하나, 곧 페이지 하나다.** 호출자 전수는 여전히 필수이지만 그것은 작업 목록이 아니라 **영역 API 설계의 입력**이다 — 페이지마다 자기 이음새에서 교체하므로 한 페이지를 옮겨도 다른 호출자는 레거시 본문으로 돈다.

환경값은 전부 `.claude/config/workspace.json` 에서 읽는다. **키가 없으면 멈추고 어느 키인지 말한다.** 이 저장소는 공개이므로 추적 파일에 회사 경로·호스트·포트·테이블명·이름을 쓰지 않는다. 산출물은 `<docs.root>` 아래에 쓴다.

| 어디 | 무엇 |
|---|---|
| 슬라이스 | `state.json` · `00-seam.md` · `01-ledger.jsonl` · `02-design-delta.md` · `04-audit.md` · `questions.md` · `corpus.json` · `pins.json` · `ignore.json` · `captures/` · `fixtures/` |
| 영역 (여러 페이지가 공유) | 영역 설계 · 도메인 문서 · 역할별 저널 |

정본은 `references/artifacts.json`. **에이전트에게 파일명을 외우게 하지 말고 절대경로를 프롬프트로 넘긴다.** 진행 상태는 `state.json` 의 `phase` 가 들고 위 상태 블록이 그것과 루프 회차·상한·토글을 찍는다. 게이트에서 세션이 끊기는 것이 정상이므로 재개는 그 줄로 하고, 들어가기 전에 그렇게 말한다.

`depth` 는 `state.json` 에 있고 모든 하위 에이전트에 넘긴다. **레드팀 라운드는 기본 0** 이고, 뒤 단계가 원장에 없는 규칙을 발견하면 그 증거를 들고 한 라운드를 켠다.

## 루프와 게이트

| 루프 | Phase | 닫히는 조건 | 상한 |
|---|---|---|---|
| L0 추출 | 1 | 골든 전부 identical **그리고** 린트 위반 0 | 3 |
| 커버리지 | 2 | 본문의 모든 문장 범위에 규칙 ID | 2 |
| L1 구현 | 4 | 빌드·단위·아키텍처 규칙 green | 5 |
| L2 동등성 | 5 | `slicecheck` 단계 3~6 통과 | 5 |
| L3 완전성 | 6 | 기계 검사 전부 통과 **그리고** 감사 PASS | 3 |

**상한은 `state.json` 의 값이고 `slicecheck` 가 증가시킨다. 닿으면 멈추고 사람에게 보고한다 — 게이트와 다른 장치이고 위임되지 않는다.**

사람이 멈추는 곳은 셋이고 전부 한 페이지 분량이다. **묻는 단계**(0.5) · **G1**(1, 편집 전) · **G2**(3 후). Do not proceed on silence at any of them. 계획이 안 바뀌는 재진입은 G1 을 다시 지나지 않고, Phase 3 을 다시 지나면 G2 도 다시 지난다.

## Phase 0 — 준비

1. `workspace.json` 을 읽는다. 없으면 example 을 복사하라고 말하고 멈춘다.
2. 페이지를 정한다. 사용자가 지목했으면 그것을 쓰고, 아니면 `slice-scout` 를 부른다 — 직접 고르지 마라.
3. `phpseam callers <symbol>` 로 **호출자 전수**를 뽑는다. 이번에 옮기지 않는 호출자는 `00-seam.md` 의 `스왑 위험` 절에 명시한다 — 같은 메서드를 정반대 계약으로 쓰는 호출자가 실제로 있었다.
4. 슬라이스 디렉터리와 `state.json` 을 만든다(형식은 설계 문서 1.6장). 이미 있으면 **재개**.
5. `slicecheck <slice-dir> --stage 1,2` — 환경 검증 넷과 **잡음 바닥 측정**. exit 3 은 "검사할 수 없었다"이고 통과가 아니다.

**`ignore.json` 은 그 잡음 바닥에서 시작한다.** 실제 경로를 모르는 시점에 추측으로 만든 목록은 실제 결함을 숨긴다. 나중에 더하는 항목은 **승인된 원장 행 ID 를 가리켜야** 한다.

## Phase 0.5 — 묻기 (★사람)

코드에 없는 정보가 설계에 필요하다. 페이지에서 의문을 뽑아 `questions.md` 에 질문 목록을 만들고 사람에게 답을 받는다. 셋을 묻는다: **이 기능을 누가 왜 쓰는가 · 발견된 동작 중 의도인지 결함인지 사람만 아는 것 · 화면에 남아도 되는 규칙.** 답은 영역 단위로 누적되므로 같은 영역의 두 번째 페이지에서는 질문이 줄어든다.

답이 없는 항목은 `모른다` 로 명시적으로 적고 **그 상태로 Phase 3 에 들어가지 않는다.** 막지 않으면 추측이 들어가고, 추측은 원장에 사실처럼 적힌다.

## Phase 1 — 이음새 추출 (★G1 · L0)

`Agent(subagent_type: "php-seam-extractor")`, `mode: 계획`. 넘길 것: 페이지 절대경로 · 대상 메서드 · 슬라이스 디렉터리와 `00-seam.md`·`corpus.json`·`pins.json`·저널의 **절대경로** · depth · **"계획만 쓰고 멈춰라, 파일을 편집하지 마라"**. `## 요약` 20줄을 첫 절로, 최종 응답 300단어 이내.

**G1 을 사람에게 제시한다** — 편집 계획의 줄 범위(가드·파싱·이동·바인딩) · 함수 시그니처 · 막는 구간과 그 처리 · 골든 corpus · 정규화 규칙 · 호출자 전수. 승인 후 같은 에이전트에 `mode: 추출` 로 다시 지시하면 L0 를 스스로 돈다.

```
htmlsnap capture (before) → phped 편집 → phpseam lint → capture (after)
                          → htmlsnap compare   (identical 까지, 상한 3)
                          → phpseam pin        (옮긴 본문의 바이트 해시 고정)
```

**이 단계의 오라클은 골든 마스터다.** 아직 백엔드가 없고 확인할 것은 "PHP 내부 리팩터가 화면을 바꾸지 않았다" 하나다. 캡처가 `logged_out`·`error_page` 플래그를 달면 기준선이 될 수 없다 — 미인증 응답은 200 으로 오고 로그아웃된 화면끼리는 언제나 identical 이다.

## Phase 2 — 원장 (커버리지)

`Agent(subagent_type: "php-behavior-analyst")`. 넘길 것: `00-seam.md`·`01-ledger.jsonl`·`references/ledger-format.md`·`questions.md`·저널의 절대경로 · 페이지 · 대상 메서드 · depth.

JSONL 한 줄이 규칙 하나이고 열마다 주인이 하나다. 분석가는 `rule`·`class`·`src`·`range` 를 쓰고 `obs` 는 `대기` 로 둔다. 커버리지가 닫히는 조건은 **본문의 모든 문장 범위에 규칙 ID 가 붙는 것**이다.

**분류 판정과 ID 배정은 오케스트레이터가 한다**(append-only). 루브릭은 포맷 정본이고, 특히 화면에서만 강제되는 규칙은 `경계` 가 아니라 아직 안 옮겨진 `도메인` 이다. `obs` 는 코퍼스가 정해진 뒤 채운다 — 심을 수 있는 픽스처는 `이중실행:`/`골든:` 이 되고 못 심는 것만 `불가:<유형>` 이다. **미리 `불가` 를 쓰면 심을 수 있었던 것까지 안 심는다.**

## Phase 3 — 설계 델타 → ★G2

`Agent(subagent_type: "backend-slice-designer")`. 넘길 것: 원장·`02-design-delta.md`·`00-seam.md`·`questions.md`·**영역 설계**·저널의 절대경로 · depth.

**설계자는 영역 설계를 읽고 이 규칙들의 델타만 쓴다.** 자원 모양·에러 매핑·인가·계층 배치는 영역 문서에 있고 같은 영역의 두 번째 페이지에서 거의 바뀌지 않는다. 바뀌어야 하면 영역 문서를 제자리에서 개정하고 그 사실을 델타에 적는다. **`backend.architectureRules` 는 살아있는 파일에서 읽는다** — 첫 실행 뒤 그 규칙이 뒤집힌 적이 있다.

델타 필수 절 넷: **규칙 배치** · **부재 점검**(트랜잭션·검증·인가·멱등성·에러 매핑, 각각 새 원장 행이거나 "해당 없음 + 이유") · **교정표**(결함마다 `교정`/`보존` + 구체 입력 예 + 레거시 값·교정 값) · **표류 의심**(각각 원장 행 ID 를 달고). 되받아칠 결정도 적는다.

**G2 에서 사람이 읽는다**: 자원 모양과 그것이 화면 모양이 아닌 이유 · 배치(특히 배치되지 않은 `도메인` 행) · 교정표 전체 · 보존하기로 한 결함 · 되받아칠 결정. 승인은 원장 행에 승인자·일자로 남고, Phase 6 이 그 행을 읽어 근거가 있을 때만 넘긴다. **표류 의심마다 원장 행이 있는지 게이트에서 직접 확인한다** — 설계에만 적힌 의심은 관찰이 될 길이 없고 검사는 그 위를 초록으로 지나간다.

승인된 `교정` 마다 `ignore.json` 항목을 준비하고 `obs` 를 `제외:의도수정` 으로 바꾼다. 그대로 두면 의도된 교정이 예상 밖 불일치로 잡히고, 되돌려 받은 구현자가 할 수 있는 유일한 일은 승인된 교정을 되돌리는 것이다.

## Phase 4 — 구현·배선 (L1 · 기계 게이트)

`Agent(subagent_type: "backend-slice-builder")` **하나**가 백엔드 구현과 이음새 배선을 함께 한다. 넘길 것: 승인된 설계 델타·원장·`00-seam.md`·`ignore.json`·`pins.json`·회귀 픽스처·저널의 절대경로 · depth.

합친 이유는 스키마 필드와 어댑터 요청 필드를 함께 보는 독자가 없어서 그 사이가 사각지대였기 때문이다. 판정의 독립성은 감사자와의 분리가 지고, 그 분리는 도구 권한으로 강제된다.

끝나면 다섯이 통과해야 한다. **실패하면 사람에게 오지 않고 스스로 고친다.**

```
빌드 · 단위 테스트 · 아키텍처 규칙
phpseam check --pins pins.json                  # 레거시 본문 0 바이트 변경
phpseam lint <page.php>                         # 페이지가 허용된 모양 안
phpseam callers <symbol> --allow-file <이음새>   # 이음새 밖 호출자 없음
phpseam fields --schema <graphqlSchemaDir> --adapter <어댑터> --ledger <원장>
```

네가 볼 것은 **무엇이** green 이 됐는지다. 판정이 BFF 에 들어갔는지(리졸버가 거르거나 정렬하거나 기본값을 정하면 모듈을 잘못 골랐다) · 도메인 규칙이 질의 어댑터에 하드코딩됐는지(조건은 완성된 채로 어댑터에 넘어가야 한다) · **아키텍처 규칙 자체가 바뀌었는지**(제약을 풀어 green 이 된 빌드는 진전으로 위장한 퇴행이다) · `의도수정`·`불가` 행마다 단위 테스트 **심볼**이 인용됐는지("테스트했다"는 문장은 인용이 아니다).

## Phase 5 — 기계 검사 (L2)

```
slicecheck <slice-dir> --stage 3..7
```

dual · migrated · **독 주입** · 레거시 본문 실행 · 복귀다. **오케스트레이터는 숫자만 읽는다.** 토글은 이 스크립트만 만지고 매번 애플리케이션에서 되읽는다 — 값을 쓰는 것과 그 값이 PHP 에 도달하는 것은 다른 일이다. exit 0 통과 · 1 빨간불 · 3 **검사할 수 없었다**. 3 을 통과로 읽지 마라.

빨간불이면 **`references/routing.md` 를 읽고 원인을 정한 뒤 파견한다.** 거기에 증상·원인·담당 표와 오라클을 약하게 만들지 말라는 규칙이 있다. 예상 밖 불일치 샘플은 `dualrun-report --as-fixtures` 로 굳히고 **그 경로를 다음 builder 파견에 넘긴다.**

## Phase 6 — 완전성 (L3)

`slicecheck` 가 초록일 때만 `Agent(subagent_type: "domain-boundary-auditor")` 를 부른다. 기계가 답할 수 있는 질문을 감사자에게 시키면 비싸고, 그 답이 판단으로 포장되어 돌아온다. 넘길 것: 기계 검사 출력 전체와 `phpseam lint --template` 출력(보고용, exit 0) · 원장·설계 델타·`00-seam.md`·`04-audit.md`·저널의 절대경로 · depth.

판정 어휘는 여섯이고 **정본은 감사자 파일 하나**다. 표에 없는 어휘가 돌아오면 감사 결과가 아니라 두 파일이 갈라졌다는 신호다 — 라우팅하지 말고 그 사실을 보고한다. 판정별 되돌아갈 곳과 게이트 재통과 규칙은 **`references/routing.md`** 에 있다.

## Phase 7 — 마감

1. **저널.** 각 에이전트가 자기 역할 저널에 `{lesson, trigger, evidence, scope}` 를 남겼는지 확인한다. `evidence` 없는 항목은 항목이 아니다 — 근거 없는 자기 반성은 하네스를 나쁘게 만든다는 측정이 있다. **저널 내용을 읽지 마라.** 파일이 생겼는지만 본다.
2. **컨텍스트 델타.** 근거 있는 항목에서 `.claude/context/*.md` 에 대한 델타를 `{Add, Merge, Revise, Skip}` 로 제안하고 **사람이 `git diff` 로 승인한다.** 통째로 다시 쓰지 않는다. 장치가 대체하는 산문은 같은 델타에서 지운다.
3. **미해결 OS 결함 0.** 이 회차에 발견한 도구·훅 결함을 다음 단위로 넘기지 않는다. 오라클이 잡은 결함은 픽스처가 되고 OS 결함은 셀프테스트 사례가 된다. 결함을 안고 다음 단위로 가면 회차를 짧게 만드는 학습이 미뤄진다.
4. 서기는 **N 페이지마다** 부른다. `Agent(subagent_type: "domain-scribe")` 에 원장·감사·**영역 도메인 문서 절대경로**를 넘기고 제자리에서 개정하게 한다 — 같은 영역을 설명하는 문서가 둘이 되는 순간 SSOT 가 죽는다.
5. 사용자에게 보고한다: 원장 분류별·이관 상태별 행 수 · 두 오라클 결과와 **그것을 만든 명령** · `state.json` 의 여섯 축 · 회귀 픽스처 경로 · 도메인 문서의 열린 기획 결정 · **토글 최종 상태와 되돌리는 명령**.

**토글은 `legacy` 로 두고 끝낸다.** 검토되지 않은 코드 경로를 살려 둔 채 세션을 끝내는 것은 오케스트레이터가 내릴 결정이 아니다.

## 오케스트레이터 규율

1. **레거시 파일을 직접 읽지 않는다.** 읽어야 할 것 같으면 에이전트에게 시킬 일이다. **예외 하나**: 에이전트가 답하지 못한 구체적 의문을 확인할 때는 읽어도 되지만 **읽은 것을 산출물로 남긴다.** 문제는 읽기가 아니라 휘발이다.
2. **산출물을 통째로 읽지 않는다.** 첫 절의 `## 요약` 20줄만 읽는다. 요약으로 판단할 수 없으면 산출물을 펼치지 말고 그 에이전트에게 요약을 고치라고 되돌린다.
3. **에이전트의 최종 응답은 300단어 이내로 요구한다.**
4. **게이트에서 세션이 끊기는 것이 정상이다.** 재개는 상태 블록으로 한다. 상태를 대화에 쌓아 두지 마라.
5. **기계가 답할 수 있는 질문을 에이전트에게 시키지 않는다.** 해시·린트·호출자·필드는 `phpseam` 이, 화면 동일성은 `htmlsnap` 이, 검사 절차는 `slicecheck` 가 답한다. 에이전트에게 남기는 것은 분류·배치·판단이다.
6. **새 검사는 신뢰하기 전에 고의로 깨뜨려 본다.** 빨간불이 켜지는 것을 확인한 뒤 되돌린다.
