# 이음새의 모양

관찰·도메인 경계·교체 이음새의 높이를 **서비스 함수 하나**로 맞춘다. 규칙이 이음새 **위**에 있으면 그 이음새를 이중 실행해도 영원히 같은 값이 나오고, 아무것도 옮기지 않은 채 통과한다.

## 허용 모양 — 페이지에 남는 것은 여섯뿐

| 종류 | 무엇인가 |
|---|---|
| include | 공용 초기화 |
| guard | 인증 확인·리다이렉트·조기 종료 — **관용구는 설정에서 읽는다**(`legacy.seam.guardIdioms`) |
| parse | 요청 파라미터·세션 값을 읽어 캐스팅·기본값 처리한 대입 |
| seam-call | 서비스 함수 호출 **정확히 하나** |
| bind | 호출 결과(또는 그 원소)를 템플릿이 볼 이름에 대입 |
| template | 템플릿 include |

그 밖은 전부 **위반**이다: 조건문·반복문·삼항·산술·비교, 파싱 밖의 기본값, 문자열 안의 SQL 키워드, 허용 목록 밖의 함수 호출, 전역 쓰기. **허용 관용구를 코드에 외워 넣지 않는다** — 무엇이 가드이고 서비스 호출이고 템플릿 경로인지는 전부 설정 키가 답하고, 그 키가 없으면 판정하지 말고 멈춘다.

## 무엇이 이동하고 무엇이 남는가

**남는 것**은 가드다 — 조기 종료는 응답 자체를 바꾸므로 함수 안으로 옮기면 반환값으로 표현할 수 없다. **이동하는 것**은 그 밖의 모든 계산이다: 목록을 만들고 개수를 세고 페이징을 계산하고 표시 여부를 정하는 문장 전부. 판정 기준은 하나다 — **템플릿이 바인딩할 데이터를 만드는 데 관여하는가.**

**옮길 때 값을 고치지 않는다.** 추출은 리팩터링이지 수정이 아니다. 결함도 그대로 옮기고, 고치는 것은 설계에서 교정표로 승인받은 뒤 builder 가 한다.

## 이음새 함수가 사는 곳

**새 규약을 만들지 않고 트리에 이미 있는 것을 따른다.** 이음새는 마이그레이션이 끝난 뒤에도 남는 코드이므로 전용 디렉터리를 새로 파면 임시로 얹은 것처럼 읽힌다. 자리는 `legacy.seam.servicesDir`, 페이지가 부르는 모양은 `legacy.seam.serviceCallPattern` 이 답한다 — 둘 다 **설정에서 읽고 외워 넣지 않는다**. 표면마다 다를 수 있고 다르다는 사실은 설정에만 적혀 있다. 판정 기준은 하나다: **그 디렉터리에 이미 사는 것이 업무 로직인가, 범용 유틸리티인가.** 암호화·이미지 처리·DB 커넥션·문자열 헬퍼가 모인 디렉터리는 업무 계산이 갈 곳이 아니다. 이 트리에는 같은 역할의 클래스가 이미 있을 가능성이 높으므로 **새로 짓기 전에 먼저 찾고**, 있으면 그 이름과 호출 관례를 따른다.

## 네 개의 기계 게이트

사람 게이트가 없는 단계가 있는 이유가 이것이다. 사람 대신 넷이 막는다.

1. **모양 린트** — 페이지에 허용 모양 밖의 문장이 없는가.
2. **본문 해시 고정** — 옮긴 레거시 본문이 **0 바이트도** 바뀌지 않았는가. 정규화하지 않는다 — 정규화하는 순간 "같다"의 의미가 흐려지고 흐려진 기준은 아무것도 막지 못한다.
3. **호출자 전수** — 이음새 밖에서 대상 심볼을 부르는 곳이 없는가.
4. **필드 대조** — 백엔드가 노출한 필드를 어댑터가 실제로 요청하는가. 셋만 있던 동안 규칙이 백엔드에 있고 아무도 그것을 읽지 않는 상태가 통과했다.

## 작업 단위와 호출자 (v3)

**작업 단위는 이음새 함수 하나, 곧 페이지 하나다.** 페이지마다 이음새가 하나씩 생기고 각자의 매핑으로 같은 백엔드 API 를 부르므로, 한 페이지를 옮겨도 나머지 호출자는 레거시 본문으로 돈다 — 위험이 한 페이지 안에 갇힌다.

**그래도 호출자 전수는 설계 전에 해야 한다.** 같은 메서드를 **정반대 페이징 의미**로 쓰는 호출부가 실측되었고(하나는 페이지네이션, 하나는 무한 스크롤), 백엔드 API 는 그 전부의 계약을 알고 설계되어야 한다. 옮기지 않는 호출자는 **이름으로 적는다** — 적지 않은 제외는 누락이다. 조사를 검색 0건으로 끝내지 않는다: 동적 호출은 어떤 정적 도구에도 보이지 않고 그 0 은 "없다"와 같은 모양으로 도착한다.
