# 이음새의 모양

v1 은 세 높이가 달랐다 — 관찰은 화면에서, 도메인 경계는 페이지 스크립트에, 교체 이음새는 데이터 접근 계층에. 규칙이 이음새 **위**에 있으면 이음새를 이중 실행해도 영원히 같은 값이 나온다. 그래서 v2 는 세 높이를 **서비스 함수 하나**로 맞춘다.

## 허용 모양

페이지 스크립트에 남는 것은 여섯 종류뿐이다.

| 종류 | 무엇인가 |
|---|---|
| include | 공용 초기화 |
| guard | 인증 확인·리다이렉트·조기 종료 — **관용구는 설정에서 읽는다**(`legacy.seam.guardIdioms`) |
| parse | 요청 파라미터·세션 값을 읽어 캐스팅·기본값 처리한 대입 |
| seam-call | 서비스 함수 호출 **정확히 하나** |
| bind | 호출 결과(또는 그 원소)를 템플릿이 볼 이름에 대입 |
| template | 템플릿 include |

그 밖은 전부 **위반**이다. 조건문·반복문·삼항·산술·비교, 파싱 밖의 기본값, 문자열 안의 SQL 키워드, 허용 목록 밖의 함수 호출, 전역 쓰기.

**허용 관용구를 코드에 외워 넣지 않는다.** 무엇이 가드인지, 무엇이 서비스 호출인지, 무엇이 템플릿 경로인지는 전부 설정 키가 답한다. 그 키가 없으면 판정하지 말고 멈춘다.

## 무엇이 이동하고 무엇이 남는가

**남는 것**: 가드. 조기 종료는 응답 자체를 바꾸므로 함수 안으로 옮기면 반환값으로 표현할 수 없다.

**이동하는 것**: 그 밖의 모든 계산. 목록을 만들고, 개수를 세고, 페이징을 계산하고, 표시 여부를 정하는 문장 전부. 판정 기준은 하나다 — **템플릿이 바인딩할 데이터를 만드는 데 관여하는가.**

**옮길 때 값을 고치지 않는다.** 추출은 리팩터링이지 수정이 아니다. 결함도 그대로 옮긴다. 고치는 것은 설계에서 교정표로 승인받은 뒤 구현이 한다.

## 이음새 함수가 사는 곳

**새 규약을 만들지 않고 트리에 이미 있는 것을 따른다.** 이음새는 마이그레이션이 끝난 뒤에도 남는 코드이므로, 전용 디렉터리를 새로 파면 임시로 얹은 것처럼 읽힌다. 자리는 `legacy.seam.servicesDir`(표면 docroot 기준 상대 경로)이 답하고, 페이지가 부르는 모양은 `legacy.seam.serviceCallPattern` 이 답한다. 두 값 모두 **설정에서 읽고 코드나 프롬프트에 외워 넣지 않는다** — 표면마다 다를 수 있고 다르다는 사실은 설정에만 적혀 있다.

자리를 고를 때의 판정 기준은 하나다: **그 디렉터리에 이미 사는 것이 업무 로직인가, 범용 유틸리티인가.** 암호화·이미지 처리·DB 커넥션·문자열 헬퍼가 모여 있는 디렉터리는 업무 계산이 갈 곳이 아니다. 성격이 다른 것이 섞이면 이음새를 찾는 사람이 어디를 봐야 하는지 알 수 없게 된다. 그리고 이 트리에는 이미 같은 역할의 클래스가 있을 가능성이 높으므로, **새로 짓기 전에 먼저 찾는다.** 있으면 그 이름과 호출 관례를 그대로 따르고, 설정값이 그것과 어긋나면 설정 쪽을 고친다.

## 세 개의 기계 게이트

사람 게이트가 없는 단계가 있는 이유가 이것이다. 사람 대신 세 가지가 막는다.

1. **모양 린트** — 페이지에 허용 모양 밖의 문장이 없는가.
2. **본문 해시 고정** — 옮긴 레거시 본문이 **0 바이트도** 바뀌지 않았는가. 정규화하지 않는다. 정규화하는 순간 "같다"의 의미가 흐려지고, 흐려진 기준은 아무것도 막지 못한다.
3. **호출자 전수** — 이음새 밖에서 대상 심볼을 부르는 곳이 없는가.

## 슬라이스의 단위

슬라이스는 진입점 둘이 아니라 **대상 심볼을 부르는 페이지 전부**다. 모바일·목록·비동기 호출자가 포함된다. 실제로 같은 메서드를 **정반대 페이징 의미**로 쓰는 호출부가 있었다 — 하나는 페이지네이션, 하나는 무한 스크롤. 백엔드가 파라미터를 "정상적으로" 해석하도록 고치면 그 호출부가 조용히 깨진다.

페이지마다 이음새가 하나씩 생기고, 각자의 매핑으로 같은 백엔드 API 를 부른다. 범위를 좁힐 때는 **제외한 호출자를 이름으로 적는다.** 적지 않은 제외는 제외가 아니라 누락이다.

호출자 조사는 검색 0건으로 끝내지 않는다. 동적 호출은 어떤 정적 도구에도 보이지 않고, 그 0 은 "없다"와 같은 모양으로 도착한다.
